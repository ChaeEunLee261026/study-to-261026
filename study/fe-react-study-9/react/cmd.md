### CRA PJT 생성
npx create-react-app 프로젝트명

### CRA PJT 실행
해당 경로로 이동
npm start
or
npm run start

### VITE PJT 생성
npm create vite@latest 프로젝트명

옵션.
React
Javascript
Eslint

### VITE PJT 실행
해당 PJT 경로로 이동
npm run dev

### node_modules 폴더가 존재하지 않는 경우
해당 PJT경로에서 package.json 파일 존재 확인
npm install

### 실행중인 서버종료
Ctrl + C
